rxn-bench-gantry
================

SiLA2 gantry motion-platform server for the Ames Lab automated chemistry bench.
Runs on the Raspberry Pi, communicates with Moonraker/Klipper over HTTP,
and exposes motion commands as gRPC calls via the UniteLabs CDK.
