rxn-bench-dosing-pump
=====================

SiLA2 device server for the Atlas Scientific EZO-PMP peristaltic dosing pump
on the Ames Lab rxn bench. Supports volume dispensing, dose over time,
constant flow rate, and continuous dispensing over the EZO UART protocol.
