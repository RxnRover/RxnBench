Backend  (``rxn_bench``)
=======================

Runs on the Raspberry Pi as a **SiLA2 server**.  It wraps Klipper/Moonraker for
motion control, a pH sensor driver, and a camera interface, each exposed as a
SiLA2 Feature over gRPC.
